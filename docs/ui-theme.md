# Radiant UI Theme

## 核心气质

Radiant 的界面应该是白底、黑字、红色点亮，而不是大面积渐变或厚重玻璃。`learn` 页面目前最接近目标：信息密度高、装饰克制，红色只用于进度、状态和品牌记忆点。

## 色彩

- 主背景：`#FFFFFF` 或 `#FAFAFA`，设置、学习、详情这类工具页优先白底。
- 主文字：`#1A1A1A`，关键标题用 800-900 字重。
- 辅助文字：`rgba(26, 26, 26, 0.42-0.52)`。
- 品牌红：`#E63946`，只用于进度、选中、危险、收藏、orbit 外圈。
- 浅红底：`rgba(230, 57, 70, 0.08-0.12)`，用于状态底，不做页面背景。
- 深色主按钮：`rgba(26, 26, 26, 0.9)`，用于主要行动，例如 learn 的“查看/再来一组”。

## 形状

- 品牌按钮/底部 CTA：`999rpx` 胶囊。
- 内容卡片：`16-22rpx`，避免过圆。
- 设置/列表分组：`24-28rpx`，但内部 item 用更小圆角。
- orbit：外容器 `72rpx`，内部环 `42rpx`，环线 `3rpx`，保持 learn/detail/settings 一致。

## 光影

- 阴影只用于抬高层级，不做内部彩色光斑。
- 页面背景不放红色 radial glow。
- 红色 glow 只能作为外围状态感：`0 0 24-38rpx rgba(230, 57, 70, 0.2-0.4)`。
- 卡片阴影维持轻量：`0 8-18rpx 20-42rpx rgba(26, 26, 26, 0.035-0.075)`。
- 避免同时出现：渐变背景、内高光、外 glow、分割线、伪元素光斑。最多两种。

## 组件规则

- 主 CTA：深色填充 + 白字，参考 `learn__view-button`。
- 次入口：白/浅灰底 + 红色图标或文字，参考收藏入口。
- 分组列表：白底页面上用极浅灰分组，不使用脏色背景。
- 底部操作栏：白色半透明 + blur 可以保留，但不要大面积红光。
- 音标/audio tag：浅灰胶囊，内部白色圆形 audio，是目前可复用模式。

## 首页特殊规则

首页已经有图片背景，底部按钮必须安静：

- 外层胶囊用于承载组合关系。
- 收藏是左侧小入口，红色实心星表达功能。
- 开始是右侧主行动，深色胶囊表达优先级。
- 不在按钮内部做红色光斑；红色只给收藏图标、极轻边缘或状态。
