# 清空学习进度

用于测试阶段重置学习进度，保留集合、索引、词书、单词和语料内容。

默认会清空：

- `user_word_progress`
- `user_book_progress`

不会清空：

- `words`
- `wordbooks`
- `wordbook_words`
- `word_learning_content`
- `content_lines`
- `content_line_words`
- `content_topics`
- `users` 用户设置

## 云函数

函数名：`learn-submit`

测试事件：

```json
{
  "action": "resetProgress",
  "confirm": "RESET_USER_WORD_PROGRESS",
  "scope": "all"
}
```

返回示例：

```json
{
  "ok": true,
  "scope": "all",
  "removed": 30,
  "removedByCollection": {
    "user_word_progress": 28,
    "user_book_progress": 2
  },
  "resetUserProfile": false,
  "usersUpdated": 0
}
```

## scope

- `all`：清空全部用户的学习进度集合。当前 MVP 只有自己测试数据时使用。
- `currentUser`：只清当前调用者的 `userId` 数据。以后多用户测试时使用。

## 重置用户设置

一般不需要重置 `users`，因为里面有每日目标、当前词书、昵称等设置。

如果确实要把 onboarding / 当前词书偏好也重置，测试事件加：

```json
{
  "action": "resetProgress",
  "confirm": "RESET_USER_WORD_PROGRESS",
  "scope": "all",
  "resetUserProfile": true
}
```

## 本地缓存

清完云端后，开发者工具里也清一次本地缓存，重点是：

```text
progress.*
today.*
todayDone.*

```
