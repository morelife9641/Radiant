## 4. 数据库权限

小程序端没有直接数据库访问，所有集合应设置为客户端不可直接读写，统一通过云函数访问。

- [ ] 用户不能直接读写 `users`、`user_word_progress`、`user_book_progress`。
- [ ] 用户不能直接修改 `words`、`wordbooks`、`wordbook_words`、语料和关系集合。
- [ ] 用普通体验账号验证无法从客户端直接查询其他用户数据。
- [ ] 用普通体验账号调用 `learn-submit.resetProgress` 并传 `scope: all`，确认返回 `FORBIDDEN_SCOPE` 且其他用户数据不变。

- [ ] 数据库里所有图片、语料音频对应的 COS 域名都已加入合法域名。
- [ ] COS 对象允许匿名读取，响应状态为 200，Content-Type 与音频格式一致。

## 7. 真机回归

- [ ] 新用户：首次进入 -> 选目的 -> 选词书 -> 完成引导。
- [ ] 老用户：删除小程序后重新进入，词书、昵称、目标和进度恢复。
- [ ] 学习：答对、答错、延迟重试、查看详情、下一题。
- [ ] 状态：收藏、取消收藏、删除、恢复学习。
- [ ] 复习：到期词可见，mastered/ignored 不进入队列。
- [ ] 切换词书后，首页已认识数不会混入其他词书。
- [ ] 每日目标中途从 10 改为 20、从 20 改为 10，分母和剩余词数正确。
- [ ] 上海时间 23:59 / 00:01 跨日后生成新任务。
- [ ] iOS 与 Android 分别测试静音开关、弱网、断网和重新联网。
- [ ] 搜索、详情 token 浮层、近义词、反义词、语料例句均可用。
