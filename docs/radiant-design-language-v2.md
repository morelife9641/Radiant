# Radiant Design Language v2

> Radiant.AI 的视觉系统规范：以 Home 的沉浸式光感为品牌锚点，把学习、查词、收藏和历史统一成同一套「光照下的内容工具」。

状态：设计基线
适用范围：`home` 以外的内页，优先覆盖 `learn`、`word-detail`、`favorites`、`learning-history`
设计原则：保留 Home 的辨识度，不复制 Home 的背景图；内页使用稳定、温暖、可阅读的画布承接内容。

---

## 1. 核心定义

### 1.1 一句话

Radiant 是一款温暖、克制、沉浸式的场景化英语学习产品。

### 1.2 视觉隐喻

Home 是光源，其他页面是光照下的内容：

| 页面 | 视觉角色 | 体验关键词 |
| --- | --- | --- |
| Home | 光源 | 沉浸、唤起兴趣 |
| Learn | 聚光 | 专注、清晰、即时反馈 |
| Word Detail | 阅读灯 | 深入、安静、可探索 |
| Favorites | 留下的光 | 轻量、快速回顾 |
| History | 光的轨迹 | 积累、连续、正反馈 |

### 1.3 设计性格

应该有：

- 温暖，但不是甜腻的儿童产品。
- 极简，但不是空白或冷漠。
- 有情绪，但不通过强动效制造刺激。
- 有内容层级，但不做资料库式的信息堆叠。
- 有品牌色，但让内容和可读性优先。

不应该有：

- 页面之间各自使用一套渐变和主色。
- 大量高饱和红色、橙色、绿色同时出现。
- 每一行内容都被包在独立卡片中。
- 纯装饰性的 glow、玻璃、内高光叠加。
- 游戏化徽章、烟花、排行榜式的竞争暗示。

## 2. 视觉架构

采用三层 token：

```text
Primitive 原始值
    ↓
Semantic 语义值
    ↓
Component 组件值
```

页面和组件只使用 Semantic 或 Component token，不直接写颜色 hex。原始色只在 `miniprogram/styles/tokens.wxss` 的 Primitive 区域出现。

### 2.1 页面层级

```text
Page Canvas       稳定的暖白画布
Section           由间距组织的内容区块
Paper Card        需要抬高层级的内容卡
Interactive       可点击、可选中、可反馈的控件
```

默认不为每个 section 添加卡片。只有需要聚焦、点击或形成内容分组时才使用 Paper Card。

### 2.2 页面背景

内页统一采用暖白画布：

```text
基础画布：#F5F1EB
纸张表面：#FFFCF7
顶部光晕：浅杏色或浅珊瑚色，透明度不高于 0.24
```

允许顶部有一层非常淡的 radial glow，但不能成为彩色背景。内页不使用明显的三段式渐变。

Home 继续保留全屏图片、暗色 veil、玻璃 dock 和白色文字；它是整个系统中唯一允许大面积沉浸式背景的页面。

## 3. Tokens

### 3.1 Primitive 色彩

| Token | 值 | 说明 |
| --- | --- | --- |
| `--ink-950` | `#1D1D1B` | 主文字、深色 CTA |
| `--ink-800` | `#393936` | 强调正文 |
| `--ink-600` | `#62625D` | 次级文字 |
| `--ink-450` | `#898982` | 辅助文字、说明 |
| `--neutral-50` | `#F4F4F0` | 中性画布 |
| `--warm-50` | `#FFFCF7` | 纸张表面 |
| `--warm-100` | `#F7ECDE` | 暖色浅底 |
| `--amber-500` | `#C77924` | Ember 主色 |
| `--amber-700` | `#8C4D16` | Ember 深色 |
| `--coral-100` | `#F1DDD7` | Coral 浅底 |
| `--coral-500` | `#C46152` | Coral 主色 |
| `--coral-700` | `#903F36` | Coral 深色 |
| `--sage-100` | `#DDECE3` | 成功浅底 |
| `--sage-700` | `#367455` | 成功文字 |
| `--rose-100` | `#F2DDD8` | 错误浅底 |
| `--rose-700` | `#A3463D` | 错误文字 |

### 3.2 Semantic 色彩

建议在 `tokens.wxss` 中保持以下语义命名：

```css
--color-background: var(--neutral-50);
--color-foreground: var(--ink-950);
--color-card: var(--warm-50);
--color-card-foreground: var(--ink-950);
--color-primary: var(--coral-500);
--color-primary-deep: var(--coral-700);
--color-primary-light: var(--coral-100);
--color-secondary: rgba(55, 55, 51, 0.055);
--color-secondary-foreground: var(--ink-800);
--color-muted-foreground: var(--ink-450);
--color-border: rgba(48, 48, 44, 0.10);
--color-border-strong: rgba(48, 48, 44, 0.20);
--color-success: var(--sage-700);
--color-success-bg: var(--sage-100);
--color-warning: var(--amber-500);
--color-error: var(--rose-700);
--color-error-bg: var(--rose-100);
```

### 3.3 页面主题

每个页面只声明一个页面强调色：

```css
/* learn daily */
--page-accent: var(--amber-500);
--page-accent-deep: var(--amber-700);
--page-accent-wash: rgba(199, 121, 36, 0.12);

/* learn review / favorites */
--page-accent: var(--coral-500);
--page-accent-deep: var(--coral-700);
--page-accent-wash: rgba(196, 97, 82, 0.12);
```

状态色只能表达状态，不能作为页面装饰色：

```text
正确 / 完成：Sage
错误 / 忽略：Rose
提醒 / 待处理：Amber
```

### 3.4 字体与行高

| 角色 | 字号 | 字重 | 行高 |
| --- | ---: | ---: | ---: |
| 页面标题 | 36rpx | 700 | 1.25 |
| 区块标题 | 28rpx | 700 | 1.35 |
| 正文 | 28rpx | 400~500 | 1.6 |
| 辅助文字 | 22rpx | 500 | 1.4 |
| 标签 | 20rpx | 600~700 | 1 |
| 展示单词 | 64~72rpx | 700 | 1.05 |
| 统计数字 | 44~56rpx | 800 | 1 |

中文使用系统无衬线字体；英文使用系统无衬线字体。英文例句应优先保证行长和行高，不使用装饰性字体。

### 3.5 间距、圆角、阴影、动效

```text
间距：8 / 16 / 24 / 32 / 48 / 64rpx
页面左右边距：32rpx
Paper Card 圆角：20rpx
普通控件圆角：12rpx
按钮圆角：16rpx
胶囊圆角：999rpx
普通阴影：0 8rpx 24rpx rgba(44, 42, 38, 0.06)
抬高阴影：0 16rpx 36rpx rgba(44, 42, 38, 0.11)
```

```text
颜色切换：150ms ease-in-out
按下反馈：120ms ease-out
卡片/页面进入：220ms ease-out
较慢的图片或页面过渡：320ms
```

## 4. 组件规范

### 4.1 Page Navigation

```text
高度：72~88rpx
左侧：返回按钮 60rpx 触控区域
中部：页面标题或状态
右侧：一个主要辅助动作，必要时使用等宽占位
```

导航不使用厚重底栏，不添加强分割线。标题应保持统一的 36rpx / 700。

### 4.2 Paper Card

```text
背景：var(--color-card)
边框：1rpx solid var(--color-border)
圆角：20rpx
内边距：24rpx
阴影：var(--shadow-soft)
```

Card 变体：

| 变体 | 用途 | 特征 |
| --- | --- | --- |
| `default` | 内容分组 | 轻边框、轻阴影 |
| `interactive` | 可点击内容 | 按下缩放、边框变深 |
| `selected` | 选中内容 | 主色浅底、主色边框 |
| `status-success` | 正确、完成 | Sage 浅底 |
| `status-error` | 错误、需复习 | Rose 浅底 |

### 4.3 Button

| 变体 | 用途 | 视觉 |
| --- | --- | --- |
| `primary` | 当前页面最重要行动 | 深色或页面主色填充、白字 |
| `secondary` | 次要行动 | Paper 底、Ink 字、强边框 |
| `ghost` | 轻量操作 | 透明底、次级文字 |
| `destructive` | 删除、忽略 | Rose 色，仅用于明确危险操作 |

```text
标准按钮：84rpx 高
小按钮：64rpx 高
底部 CTA：84rpx 高，999rpx
图标按钮：60rpx 触控区域
```

状态优先级：`disabled > loading > active > focus > pressed > default`。

### 4.4 Pill / Tag

用于：音标、词性、筛选、范围切换、学习状态。

```text
高度：48~56rpx
左右内边距：16~20rpx
字号：20~22rpx
```

标签不要承载长句；超过一行的内容应使用正文或卡片。

### 4.5 Empty State

统一结构：

```text
小光点或线性图标
标题
一行解释
一个主要行动
```

空状态不使用夸张插画，不使用与页面无关的装饰。

## 5. 页面设计规格

## 5.1 Learn：聚光学习台

目标：让用户在一个页面内完成一次判断，不被装饰和次要数据打断。

### 结构

```text
Page Nav
  返回 / 今日新学或复习队列 / 03·10 / 收藏
Progress Line
Word Stage
  单词 / 音标 / 播放 / 词性
Question Prompt
Choice Stack
Bottom CTA
```

### 规格

```text
页面背景：暖白画布，daily 使用 Ember 光晕，review 使用 Coral 光晕
单词字号：64~72rpx
音标字号：22rpx
选项高度：128~144rpx
选项间距：16rpx
底部 CTA 高度：84rpx
页面左右边距：32rpx
```

### 视觉规则

- 单词应成为内容区中心，而不是被挤在导航区域。
- 题目和选项使用 Paper Card，不使用大面积强渐变。
- daily 使用 Ember 作为进度和焦点；review 使用 Coral。
- 答对只改变底色、边框和状态图标，不做强动画。
- 结束页保留“完成 / 答对 / 需要再看 / 再来一组 / 返回首页”五个信息点即可。

### 推荐文案

```text
今日新学 · 03 / 10
复习队列 · 02 / 08
查看答案
查看详情
继续学习
```

## 5.2 Word Detail：阅读灯

目标：让用户从一个词自然地阅读到释义、语料、学习内容和词关系。

### 结构

```text
Word Header
  单词 / 音标 / 播放 / 收藏 / 忽略
Scrollable Tabs
  基础 / 原文 / 学习 / 近义 / 反义 / 辨析
Content Sections
```

### 规格

```text
标题字号：56~64rpx
中文核心释义：28~32rpx
横向 Tab：56rpx 高，999rpx 圆角
区块间距：24rpx
卡片内边距：24rpx
例句字号：27~29rpx，行高 1.55
```

### 内容顺序

基础：英文短释 → 核心释义 → 词形变化 → 常用搭配 → 阅读出处。

原文：英文例句 → 中文翻译 → 来源 → 播放。

学习：考试画像 → 构词 → 语法模式 → 易错点 → 相关词。

关系：目标词 → 相关词 → 语义差异 → 一条例句。

### 视觉规则

- 只有核心释义和可点击内容使用 Card。
- 普通词义之间使用间距，不使用连续的重分割线。
- 当前单词在例句中使用浅珊瑚色底纹或下划线。
- 关系词不使用过多箭头、徽章和嵌套卡片。
- Tab 使用横向滚动胶囊，不平均压缩成很窄的五等分按钮。

## 5.3 Favorites：留下来的词

目标：快速扫读、播放、进入 Detail，并保持“我主动留下了这个词”的感觉。

### 结构

```text
页面标题 + 收藏数量 + 排序
收藏词卡列表
左滑取消收藏
```

### 收藏卡规格

```text
高度：176~196rpx
圆角：20rpx
内边距：20~24rpx
单词字号：44~48rpx
音标胶囊：32~36rpx 高
中文释义：25~27rpx
英文短释：21~22rpx，最多两行
```

### 视觉规则

- 星标固定在卡片右上角，作为收藏状态的主要标识。
- 卡片点击进入 Detail，播放按钮阻止冒泡。
- 左滑操作使用 Coral Deep，不使用纯红色危险条。
- 卡片列表间距 16rpx，不再使用过高的单卡造成滚动疲劳。

### 空状态

```text
还没有留下词语
在学习中点亮星标，喜欢的词会留在这里
[去学习]
```

## 5.4 Learning History：光的轨迹

目标：表达积累和持续感，而不是把学习行为变成 KPI 看板。

### 结构

```text
页面标题
连续学习摘要
三项关键指标
新学趋势卡
学习记录列表
```

### 规格

```text
连续天数：44~56rpx
指标数字：36~44rpx
趋势卡圆角：20rpx
图表高度：180~220rpx
记录行最小高度：104rpx
```

### 视觉规则

- 连续学习摘要使用一个低强度 Radiant 光点，不使用火焰或奖杯。
- 三项指标使用无边框指标带，用极淡竖线分隔。
- 折线图只使用 Coral 一条主线，填充透明度不高于 0.10。
- 选中日期使用小光点和浅色选中背景。
- 学习记录可以用一条极淡的竖线连接日期，但不做成复杂时间轴。

### 推荐文案

```text
已连续学习 7 天
最长 12 天
新学趋势
最近 7 天每日新学
第一束光还在路上
```

## 6. 可访问性与状态规则

### 6.1 颜色不是唯一状态

答对、答错、收藏、加载和禁用状态必须同时有颜色与以下至少一种表达：

- 文案
- 图标
- 位置
- 形状变化
- 边框变化

### 6.2 对比度

- 正文和背景保持至少 4.5:1 对比度。
- 大标题和 UI 控件保持至少 3:1 对比度。
- 浅色文字只能用于说明和非核心信息。
- 不在图片上直接放正文，必须有 veil 或稳定的对比区域。

### 6.3 加载

- 页面加载：居中光点 + 简短说明。
- 卡片加载：保留结构占位，不让页面突然跳动。
- 按钮加载：保留按钮尺寸，替换文字或加入小型 spinner。

### 6.4 错误

错误状态使用 Rose 浅底、边框和明确说明；不能只把文字变红。

### 6.5 禁止震动

遵循项目现有规范，不调用 `wx.vibrateShort` 或 `wx.vibrateLong`。所有反馈使用颜色、图标和轻量动效完成。

## 7. 实施顺序

### Phase 1：建立统一基础

1. 在 `tokens.wxss` 中补齐 Primitive → Semantic → Component 三层命名。
2. 统一内页背景、导航、卡片、按钮和 Tab。
3. 清理页面级硬编码颜色。

### Phase 2：重做四个页面

1. `learn`：重新安排单词舞台、题目卡和底部 CTA。
2. `word-detail`：统一词头、横向 Tab 和内容卡层级。
3. `favorites`：压缩收藏卡高度，强化星标和快速扫读。
4. `learning-history`：保留数据功能，降低看板感，强化光的轨迹。

### Phase 3：验证

检查以下内容：

- Home 与所有内页是否仍像同一个产品。
- 页面是否只使用一个主强调色。
- 文字、按钮和卡片是否符合统一尺寸。
- 加载、空状态、错误、选中和按下态是否完整。
- 真机上是否存在底部 CTA 遮挡、滚动区域过短或标题拥挤。
- 详情页长内容是否保持清晰的阅读节奏。

---

## 8. 最终设计判断

Radiant 不应该被描述成“红白英语学习工具”，而应该被描述成：

> 一套以沉浸式 Home 为光源、以暖白内容画布为基础、用珊瑚与琥珀点亮学习状态的场景化英语学习设计系统。

设计决策的优先级始终是：

```text
可读性 > 学习节奏 > 内容层级 > 品牌装饰
```
